# A Box of Stories
This game won 3rd place for Narrative Design at the Game Republic Student Showcase 2026! 
You find yourself trapped in a mysterious room with no recollection of how you got there. Surrounded by stories and puzzles, can you find the way out?

This game was made by a team of 2. More information is available on the game's itch.io page
